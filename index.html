WeatherSphere

A full-stack web application that combines 3D graphics with real-time weather forecasting. The frontend is built with React and TypeScript, utilizing Jotai for reactive state management to handle synchronized city selections and real-time weather updates. The 3D globe is rendered using Three.js, leveraging custom shaders to handle atmospheric effects and surface rendering. To manage the data pipeline, an Express.js backend acts as a proxy layer for the OpenWeather API, handling request routing and data normalization. The application delivers comprehensive metrics—including wind, humidity, and visibility—presented through a combination of visual cards and structured data tables for hourly and daily forecasts.

This project is hosted on Render's free tier. Please allow up to 60 seconds for the initial "cold start" as the server spins up on your first visit.

LogMyTrades

A robust, full-stack trading journal engineered for deep performance analysis and rigorous back-testing. Built with React and TypeScript, the application utilizes Jotai for client-side state management and React Query for efficient server-state synchronization and data fetching. The system features a dual-persistence architecture: registered users utilize a server-side stack consisting of NestJS, Sequelize, and SQLite, while the Guest Mode employs a local-first approach using Dexie (IndexedDB) for high-performance persistent storage. Core functionalities include granular trade logging, automated data export, and a sample-data injection system designed to provide an immediate, content-rich dashboard experience.

This project is hosted on Render's free tier. Please allow up to 60 seconds for the initial "cold start" as the server spins up on your first visit.
