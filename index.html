WeatherSphere

WeatherSphere is an interactive weather forecasting web application built with TypeScript, React, Three.js, and Express. It allows users to search for and select cities from around the world. The application presents current weather conditions, including temperature, humidity, wind, visibility, and other atmospheric details. Users can also explore hourly and daily forecasts through compact cards and data tables.
